# Leeratelier · presentatie (v0.25.0)

Deze map is gebouwd uit de bronrepo `natalia-learning-lab` met `node src/build.js --space presentatie dist/leeratelier-demo`. Niet met de hand wijzigen: pas de bron aan en bouw opnieuw.

- Adres: https://leeratelier-demo.nataliajansen.nl
- Opslag in de browser onder `philearn-presentatie-…`
- Login: één gedeelde gebruikersnaam en één wachtwoord (de hash komt bij het bouwen uit `.env.local` in de bronrepo). Dit is een drempel tegen toevallige bezoekers, geen beveiliging.
- Demo leegmaken en Demo vullen staan in de voettekst.

Zie de README van de bronrepo voor bouwen, login en testen.
